## วิธีทำให้กดลิงก์แล้วขึ้นหน้าเว็บ

### 1. อัปไฟล์

ที่หน้า repo กด **Add file → Upload files**
ลาก **ไฟล์ทั้ง 3 ไฟล์** (ไม่ใช่โฟลเดอร์ ไม่ใช่ไฟล์ zip) ลงไปในกรอบ แล้วกด **Commit changes**

> อัปถูกแล้วจะเห็นแบบนี้ที่หน้าแรกของ repo
>
> ```
> index.html
> progress-deck.pptx
> README.md
> ```
>
> ถ้าเห็นเป็นโฟลเดอร์ที่ต้องกดเข้าไปก่อนถึงจะเจอ `index.html` → **ยังไม่ถูก** ต้องลากไฟล์ขึ้นใหม่ให้อยู่ชั้นนอกสุด

### 2. เปิด Pages

**Settings → Pages →** หัวข้อ *Build and deployment*

- Source: **Deploy from a branch**
- Branch: **main** · โฟลเดอร์: **/ (root)**
- กด **Save**

### 3. รอ 1–2 นาที แล้วกดลิงก์ที่ขึ้นด้านบนของหน้า Pages

ได้ลิงก์หน้าตา `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ถ้ายังขึ้น 404

ไล่เช็กตามนี้

1. หน้าแรกของ repo เห็นคำว่า `index.html` ไหม ถ้าต้องกดเข้าโฟลเดอร์ก่อน = ผิด
2. ชื่อไฟล์เป็น `index.html` ตัวพิมพ์เล็กล้วนไหม ไม่ใช่ `Index.html` หรือ `index.HTML`
3. ใน Settings → Pages เลือกโฟลเดอร์ **/ (root)** ไม่ใช่ `/docs`
4. repo เป็น **Public** ไหม (บัญชีฟรีต้อง Public ถึงจะใช้ Pages ได้)
5. ที่แท็บ **Actions** ของ repo ดูว่า workflow ชื่อ *pages build and deployment* ขึ้นติ๊กเขียวแล้วหรือยัง ถ้ายังหมุนอยู่ให้รอ
6. กด **Ctrl + F5** หนึ่งที เบราว์เซอร์ชอบจำหน้า 404 ไว้
